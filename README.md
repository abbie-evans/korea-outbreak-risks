Data and Python code accompanying Evans *et al*., "Demographic changes and behavioural responses shape vulnerability to infectious disease outbreaks"

## Main scripts

To reproduce the figures, run the following scripts:

- Figure 1: `Figure_1.py`
- Figure 2: `model.py`
- Figure 3: `pathogen_characteristics.py`
- Figure 4: `behavioural_responses.py`
- Figure 5: `model_nigeria.py`
- Figure S1: `pairwise_correction.py`
- Figure S2: `pathogen_characteristics.py`
- Figure S3: `r0_pmo.py`

Note that all dependencies are specified in the `requirements.txt` file.

Reproduced figures will be saved into the `Figures` directory.

## Key outputs
The main generated outputs from this repository are:
1. Computation of PMO in the Republic of Korea and Nigeria given long-term demographic changes
2. Computation of PMO given pathogen characteristics
3. Computation of PMO given behavioural responses, such as in response to an increase in the retirement age
